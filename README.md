# Grafoanalisis - Curso de Perícia Grafotécnica

Landing page de vendas para o curso online de Perícia Grafotécnica. O site apresenta o conteúdo programático, informações sobre o professor, depoimentos, planos de investimento e seção de dúvidas frequentes.

## 🚀 Tecnologias Utilizadas

Este projeto foi construído com as seguintes tecnologias:

- **[React](https://reactjs.org/)** - Biblioteca JavaScript para construção de interfaces.
- **[TypeScript](https://www.typescriptlang.org/)** - Superset do JavaScript que adiciona tipagem estática.
- **[Vite](https://vitejs.dev/)** - Build tool e servidor de desenvolvimento rápido.
- **[Tailwind CSS](https://tailwindcss.com/)** - Framework CSS utilitário para estilização rápida.
- **[Lucide React](https://lucide.dev/)** - Biblioteca de ícones.

## 📁 Estrutura do Projeto

```text
grafoanalisis/

```

## 💻 Como rodar o projeto localmente

Para rodar este projeto na sua máquina, siga os passos abaixo:

Clone o repositório:

bash
git clone https://github.com/paulamelo2404/grafoanalisis.git
Acesse a pasta do projeto:

bash
cd grafoanalisis
Instale as dependências:

bash
npm install
Inicie o servidor de desenvolvimento:

bash
npm run dev
Abra o navegador em http://localhost:5173.

## 🌐 Deploy

O projeto está configurado para deploy automático na Vercel. Qualquer push na branch main dispara uma nova build e atualização do site em produção.
